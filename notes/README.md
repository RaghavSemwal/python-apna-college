# 📝 Notes

This folder stores revision notes, PDFs, and screenshots from the Apna College lectures.

## How to use

- Save lecture PDFs here with names like `01_basics_notes.pdf`
- Add hand-written note photos as `topic_handwritten.jpg`
- Keep a `quick_revision.md` here for last-minute revision

## Quick Revision Tips

- Re-watch a lecture if stuck — Apna College explains really well!
- Type every code example yourself; don't just read it.
- Solve all practice questions before moving to the next topic.
