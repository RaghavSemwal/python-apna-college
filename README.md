## 🚀 How to Use

All code is in **Jupyter Notebooks (`.ipynb`)** designed for **Google Colab**.

**Open any notebook directly in Colab:**

1. Go to [colab.research.google.com](https://colab.research.google.com)
2. Click **File → Open Notebook → GitHub**
3. Paste this repo URL and pick any notebook

**Or clone and run locally:**

```bash
git clone https://github.com/YOUR_USERNAME/python-apna-college.git
cd python-apna-college
jupyter notebook
```
